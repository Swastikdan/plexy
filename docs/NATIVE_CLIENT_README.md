# Android mobile

The mobile app is a standalone local-file library and player. Its setup, structure,
build commands, signing notes, and device checks are documented in
[apps/mobile/README.md](../apps/mobile/README.md).

There is no TV app or shared native-client package. Backend connection, account,
pairing, server playback, server downloads, LAN trust/discovery, and Cast code have
been removed from mobile.
