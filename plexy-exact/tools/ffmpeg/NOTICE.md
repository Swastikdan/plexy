# Bundled FFmpeg tools

Apple Silicon static executables: FFmpeg / ffprobe 9.0.2 from https://www.osxexperts.net/ (retrieved 2026-11-09). The download page publishes the executable SHA-256 values pinned in `tools/install-ffmpeg.ts`. No binaries are tracked in git.

These executables include GPL components (including libx264/libx265). FFmpeg licensing: https://ffmpeg.org/legal.html. Build/source information is supplied by the distributor at https://www.osxexperts.net/. FFmpeg source: https://github.com/FFmpeg/FFmpeg. Preserve the applicable GPL notices and corresponding source when distributing binaries; the repository's native build remains a personal preview.
